# Ephraim Effy Nodoh — Personal Website

This is a static, mobile-friendly personal profile website designed to give Google a clear public page for the name "Ephraim Effy Nodoh".

## Files
- index.html — main website
- styles.css — styling
- images/ — supplied photos
- robots.txt — search crawler instructions
- sitemap.xml — sitemap template
- README.txt — publishing notes

## Before publishing
1. Replace `https://example.com/` in index.html, robots.txt and sitemap.xml with the real website domain.
2. Review the family section and decide whether you want the children's names publicly displayed.
3. Confirm that the phone number and email should be public.
4. Publish the folder to a web host.
5. Add the domain to Google Search Console and submit `/sitemap.xml`.
